# Dockwarden skills

These skills capture the safe workflow for Dockwarden firmware work.

| Skill | Use it for |
| --- | --- |
| `dockwarden-firmware-safety` | Any firmware, fwupd, flash, update, repair, or recovery request. |
| `dockwarden-macos-hid-diagnostics` | macOS HID, Input Monitoring, IOKit, sandbox, or `get-devices` failures. |
| `dockwarden-verification-gates` | Builds, tests, hardware checks, release claims, and completion reports. |

Read the matching `SKILL.md` before acting. The skills prefer read-only checks and
require evidence before a success claim.
